# multinets 0.1.0

* First release of the Python version, ported from the R package 0.2.2 with the
  same features: `is_multilevel()`, `extract_highlevel()`, `extract_lowlevel()`,
  `extract_mesolevel()`, `mode_transformation()`, `layout_multilevel()`,
  `set_color_multilevel()`, `set_shape_multilevel()` and the `linked_sim` data.
* Supports both igraph and networkx graphs.
* See "Differences from the R package" in the README.
